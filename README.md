# Card & Krueger (1994) — Minimum Wages and Employment: A DID Reproduction

This repository reproduces **Tables 2, 3 and 4** and **Figure 1** of

> Card, D., & Krueger, A. B. (1994). Minimum Wages and Employment: A Case Study
> of the Fast-Food Industry in New Jersey and Pennsylvania. *American Economic
> Review*, 84(4), 772–793.

## Research design

On 1 April 1992 New Jersey raised its minimum wage from $4.25 to $5.05 per hour,
while neighbouring eastern Pennsylvania remained at $4.25. Card and Krueger surveyed
410 fast-food restaurants (Burger King, KFC, Roy Rogers, Wendy's) in both states
before (February–March 1992) and after (November–December 1992) the change, and
compared employment in a difference-in-differences (DID) design.

**Headline result:** the DID estimate is **+2.76 full-time-equivalent (FTE) workers
per store** (s.e. 1.36), i.e. the minimum-wage increase did **not** reduce fast-food
employment.

## Data

| File | Description |
|---|---|
| `data/public.csv` | Raw store-level survey data (410 stores × 46 columns). |
| `data/processed.csv` | Analysis-ready data generated by the script (adds FTE, ΔFTE, wage gap, …). |
| `DATA_DICTIONARY.md` | Column definitions for `public.csv`. |

**FTE employment** (paper p. 775) = `full-time employees + managers/assistant
managers + 0.5 × part-time employees`. Permanently-closed stores (`STATUS2 = 3`)
are assigned zero wave-2 employment; temporarily-closed stores (`STATUS2 ∈ {2,4,5}`)
are treated as missing (and set to zero in one robustness row of Table 3).

**Data access:** `public.csv` is the Card–Krueger fast-food survey, supplied through
the course data package `01` (see `DATA_ACCESS.md`). If the course data-access terms
require it, exclude `data/public.csv` from a public repository and point readers to
package `01` instead — all code and derived outputs are otherwise self-contained.

## Reproducing the results

Requirements: Python 3.9+.

```bash
# 1. create a virtual environment and install dependencies
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt          # or: make setup

# 2. regenerate processed data, Tables 2–4, Figure 1 and the report
.venv/bin/python scripts/reproduce_card_krueger.py  # or: make reproduce

# 3. (optional) build the typeset PDF report
.venv/bin/python scripts/export_pdf.py              # or: make pdf

# 4. (optional) within-NJ treatment-intensity DiD (NJ sample only)
.venv/bin/python scripts/within_nj_did.py
```

One-command build: `make all`.

## Results at a glance

**Table 3 — average FTE employment per store (standard errors in parentheses):**

| | Pennsylvania | New Jersey | Difference (NJ − PA) |
|---|---|---|---|
| FTE before | 23.33 (1.35) | 20.44 (0.51) | −2.89 (1.44) |
| FTE after | 21.17 (0.94) | 21.03 (0.52) | −0.14 (1.07) |
| Change | −2.16 (1.25) | +0.59 (0.54) | **+2.76 (1.36)** |

Within New Jersey, employment rose at the low-wage stores most exposed to the
increase and fell at high-wage stores — a within-state check consistent with the DID.
**Table 4** reduced-form regressions give an NJ coefficient of ≈ +2.3 (s.e. 1.2) and
a wage-gap coefficient of ≈ +15.7 (s.e. 6.1), in line with the published paper.

## Within-NJ treatment-intensity DiD (extension)

As a further check that does **not** rely on Pennsylvania as the control group, we
restrict the sample to New Jersey (all PA observations dropped) and exploit that
stores were exposed to the minimum-wage increase with **different intensities**. The
continuous exposure is `GAP_i = max(0, (5.05 - WAGE_ST_i) / WAGE_ST_i)`, so a store
already paying ≥ $5.05 has GAP = 0 and serves as the within-state reference.
Run: `.venv/bin/python scripts/within_nj_did.py`.

**Results (N = 293 NJ stores, dependent variable: change in FTE employment):**

| Specification | GAP coefficient | s.e. | t | p |
|---|---|---|---|---|
| GAP only | +13.08 | 6.60 | 1.98 | 0.048 |
| + chain & ownership | +12.27 | 6.82 | 1.80 | 0.073 |
| + region | +12.14 | 6.87 | 1.77 | 0.078 |

The discrete Low−High contrast (wage = $4.25 vs ≥ $5.00) is **+3.36 FTE**
(s.e. 1.28, p = 0.009): the stores most exposed to the policy gained employment
relative to the least-exposed stores. Both the continuous and discrete versions
point the same way — **no evidence of a negative employment effect**, consistent
with the between-state DID.
